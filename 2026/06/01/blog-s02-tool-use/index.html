三、真正的 Claude Code 怎么定义工具

对比表

维度 教学版 (s02) 真实 Claude Code
Schema 格式 JSON Schema Zod Schema
定义方式 TOOLS 数组（纯数据） buildTool() 工厂函数（对象）
实现与定义 分离（TOOLS + HANDLERS） 一体（同一个对象）
参数校验 无（纯依赖 schema） Zod 强校验 + validateInput()
并发控制 无（顺序执行） isConcurrencySafe() 分区
结果处理 全部返回 maxResultSizeChars 阈值 + 落盘
权限 仅 safe_path 5 步验证管线

教学版 vs 真实 CC 的代码形状

关键差异

1. Schema 格式不同

教学版用 JSON Schema——API 原生支持，声明式。CC 内部用 Zod Schema——TypeScript 生态，支持复杂校验（正则、条件、变换）。但最终都是同一个目的：告诉模型参数长什么样。

2. 定义和实现在一起 vs 分开

教学版分开是为了教学清晰——一眼看到”加工具 = 2 步”。CC 把它们打包成一个 buildTool() 调用，更方便做统一验证和注入。

3. 教学版没有的机制

  • 并发安全：只读工具（read_file、glob、ls）可以并行执行，写工具（rm、write）串行。CC 根据 isConcurrencySafe 自动分区
  • 结果落盘：工具输出太大就写文件，模型只看到摘要 + 文件路径，避免上下文撑爆
  • 5 步验证管线：Zod 校验 → validateInput → PreToolUse hooks → 权限检查 → 执行
