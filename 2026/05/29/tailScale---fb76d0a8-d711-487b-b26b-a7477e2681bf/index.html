以下是为银河麒麟 V10（ARM64）系统安装 Tailscale 并配置开机自启的完整步骤总结文档，可直接复制保存为 .md 文件。

2. 首次手动启动并完成认证（仅第一次需要）

  • 复制终端输出的链接到浏览器，使用 Microsoft、Google 或 GitHub 账号登录授权。
  • 成功后终端会显示 Success。

3. 创建 systemd 服务文件（实现开机自启）

4. 停止手动运行的 tailscaled 进程（如有）

5. 启用 systemd 服务并设置开机自启

6. 验证服务状态

应显示 Active: active (running)。

7. 验证 Tailscale 连接

  • 如果显示 Tailscale IP（如 100.x.y.z）且状态为 active，说明配置成功。

日常管理命令

操作 命令
查看连接状态 tailscale status
查看本机 IP tailscale ip
断开 Tailscale sudo tailscale down
重新连接 sudo tailscale up
重启 tailscaled 服务 sudo systemctl restart tailscaled
查看服务日志 journalctl -u tailscaled -f

注意事项

  • 认证信息保存在 /var/lib/tailscale/tailscaled.state，只需首次 tailscale up，之后守护进程会自动读取。
  • 两台电脑都安装 Tailscale 后，可以使用对方的 Tailscale IP 直接 SSH：ssh user@<对方TailscaleIP>
  • 如需启用 Tailscale 自带的 SSH 功能，可运行 sudo tailscale up --ssh（可选）。

直接复制以上内容保存为 `tailscale_install_guide.md` 即可。
